# 제작용 2D 도자기 원화

23개 박물관 예시의 실루엣을 참고해 OpenAI 이미지 생성으로 새로 그린 창작 게임 자원입니다. `models-manifest.js`의 동일 ID 자료를 화면에 렌더링한 참고 이미지와 새 공방 배경을 사용해 평면 채색·갈색 윤곽선·종이 질감을 맞췄습니다. 원본 유물의 장식은 관찰 도감에서 보고, 제작용 그림은 학생이 직접 장식할 수 있도록 비워 두었습니다. 의자·베개·향로의 기존 장식 구멍도 막아 두었습니다. 손잡이의 빈 공간과 그릇의 기능적 입구는 장식 투각과 구분합니다.

- `source/*.png`: 생성 원본을 복사한 원화. 생성 도구의 원본은 별도로 보존합니다.
- `*.webp`: 같은 원화를 화질 91, 알파 100으로 변환한 게임용 이미지.
- `manifest.json`: 원본·런타임 파일, 이미지 크기, 투명도 여부와 SHA-256.

교실용 창작 그림이며 유물의 실측 복원·정밀 복식 또는 기법 판정 자료가 아닙니다. 각 유물 자체의 출처와 권리 조건은 `../models/README.md` 및 `models-manifest.js`를 참고하세요.

제작은 Canvas 2D의 변형 애니메이션입니다. Live2D Cubism SDK 및 Cubism 모델 파일은 사용하지 않습니다. 선택한 15종의 회전은 24방향 일러스트로 지원하고, 나머지 예시는 단일 원화를 사용합니다. 실제 유물의 입체 관찰은 기존 3D 도감에서 합니다.

`rotations/source/`는 4방향씩 그린 생성 원화이며, `rotations/{id}/00.webp`부터 `23.webp`까지가 15도 간격의 게임 프레임입니다. 0·45·90도 등 기존 원화와 각도가 맞는 8방향을 재사용하고, 사이의 16방향은 별도로 생성했습니다. 모든 프레임은 투명한 640×640 캔버스에 바닥 높이를 맞췄으며 프레임별 출처와 해시는 `rotations/manifest.json`에 있습니다.

투각은 앞·뒤 벽을 분리해 합성합니다. 한쪽만 뚫으면 내부의 반대편 벽이 보이며, 두 벽의 구멍을 모두 만들고 시선상 겹친 경우에만 밖이 보입니다.
