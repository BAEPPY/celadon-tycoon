# 공방 손님 캐릭터

왕·왕비·귀족 관원·귀족 부인·도공 선생님 5명의 창작 캐릭터입니다. OpenAI 이미지 생성으로 제작하고, 사용자 제공 고려 복식 자료·왕복 설명과 사용자 제공 가게 게임의 차분한 파스텔·평면 채색·갈색 윤곽선과 새 `assets/scenes/` 배경을 참고해 화풍을 통일했습니다. 왕은 담황색의 넉넉한 상포·자색 허리띠·높은 관모를 적용하고 측면의 과도한 부풀음과 팔 연결을 수정했습니다.

- `source/*.png`: 투명 배경의 4방향 원본 시트. 앞·뒤·왼쪽·오른쪽 순서이며 생성 원본의 그림을 코드로 잘라 변형하지 않습니다.
- `*.webp`: 같은 시트를 화질 91·알파 100으로 변환한 게임용 자원입니다. CSS에서 네 구간을 나누어 표시합니다.
- `manifest.json`: 크기·알파·방향 순서·원본과 런타임 파일 해시를 기록합니다.

이 이미지는 수업용 게임의 창작 재현입니다. 특정 인물의 초상, 유물의 실측 복원, 복식 고증의 확정 자료로 제시하지 않습니다. 도공의 작업복은 교육용 창작 설정입니다. 게임의 손님 도감에서 각 방향을 볼 수 있고 PNG 시트를 저장할 수 있습니다.
