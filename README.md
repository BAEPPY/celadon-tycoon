# 고려청자 타이쿤 2

초등학교 5학년 사회 「고려청자의 우수성과 다양한 쓰임」 수업을 위한 개별 주문 제작 게임입니다.

## 수업 흐름

53가지 가상 왕실·귀족 주문 중 한 건을 무작위로 받고, 9가지 쓰임 분류에서 형태를 고릅니다. 기존 30개 주문에 도감 예시 23개를 각각 활용한 주문을 추가했습니다. 잔·잔과 받침·연적·조롱박 병도 제작하고, 같은 쓰임 안에서 23개 예시의 세부 형태를 선택할 수 있습니다. 상감·투각·무늬 없는 표현을 선택하고, 장식과 건조→초벌→유약→재벌 과정을 진행합니다. 완성품의 쓰임과 솜씨를 설명하고, 고객 피드백을 보고 다시 만들 수 있습니다.

- 기본 활동: 13분, 주문 한 건 완성 후 서로 다른 쓰임 비교
- 자동 점검: 쓰임 40점, 제작 과정 30점, 주문 특징 10점
- 자기점검: 쓰임 설명 10점, 우수성 설명 10점. 문장 길이와 자기확인 여부만 검사하며 내용의 정확성을 자동 판정하지 않습니다. 교사가 최종 확인합니다.
- 속도나 그림 실력, 무작위 결과는 채점하지 않습니다.
- 주전자 몸통의 투각은 이 게임의 단층 모형에서 물이 새므로 주문 특징 점수를 얻지 못합니다. 역사 속 모든 투각 주전자를 일반화한 판정이 아닙니다.

## 저장과 개인정보

학생 이름·로그인·서버 데이터베이스를 사용하지 않습니다. 제작 중인 작품과 완성품 최대 60건은 각 브라우저의 localStorage에 저장합니다. 다른 기기와 자동 공유되지 않으며 브라우저 기록을 삭제하면 지워질 수 있습니다. PNG 작품 카드를 내려받아 교사가 안내한 패들렛 등으로 직접 공유합니다. 글꼴을 불러올 때 Google Fonts에 접속하며, 글꼴을 불러오지 못해도 기본 글꼴로 동작합니다.

## 실행과 검증

Node.js 20 이상에서 실행합니다. Three.js와 esbuild 버전을 고정해 두었습니다.

```sh
npm ci
npm test
npm run build
npm start
# http://127.0.0.1:4173
```

`dist/`를 정적 호스팅에 게시합니다. Vercel은 `vercel.json`의 buildCommand와 outputDirectory를 사용합니다. 서버 함수나 API 키가 필요하지 않습니다.

검증한 기능: 30건 랜덤 주문과 단일 활성 주문, 30건 순환 중복 방지, 박물관 3D 관찰, 상감/투각/무늬 없음 제작, 잘못된 순서 안내, 형태 오류와 재제작, 자기점검 분리, 개인 작품함과 진행 복원, PNG 저장, 모바일 가로 넘침 방지.

공방 배경은 내장 ImageGen으로 제작한 독창 일러스트입니다. 왕·귀족·주문은 학습용 가상 설정입니다. `art.js`의 그림은 직접 작성한 SVG이며 실제 문화유산의 정밀 복제나 3D 스캔이 아닙니다. 제작 과정과 시간은 수업용으로 단순화했습니다. 모든 청자가 상감청자인 것은 아닙니다.

## 3D 도감과 한 번에 한 주문

`minichungjamuseum`을 참고한 GLB 23개를 게임 안에서 로딩합니다. 드래그 회전, 확대, 초기 시점 복귀를 지원하며, 닫거나 모델을 바꾸면 이전 로딩과 그래픽 자원을 해제합니다. 스캔 형상, 사진 기반 재현, 참고 청자색의 차이는 각 모델에 표시합니다. 출처와 이용 조건은 `assets/models/README.md`를 확인하세요. 제작 작업대와 관찰 도감 모두 실제 3D 모델을 사용합니다.

진행 중인 주문이 있으면 처음 화면으로 돌아가거나 새로고침해도 그 주문을 이어 합니다. 납품 후에만 다음 손님을 받습니다. 각 53건 순환에는 같은 주문이 없고, 순환 경계에서도 최근 두 주문의 즉시 재등장을 피합니다. 주문별 결과물과 명성 점수는 작품 ID 기준으로 갱신되어 재제출해도 같은 작품이 중복 저장되지 않습니다.

앱 소스 진입점은 `app-v3.js`이며 빌드 후 `dist/app.js`가 됩니다. 기존 `app.js`는 1차 버전의 보관 소스입니다.

### 3D 제작 작업대

작업대는 `craft-3d.js`에서 박물관 GLB의 실제 형상을 사용합니다. 목표 윤곽을 따라 깎은 부위와 비율에 따라 흙덩어리에서 목표 형상으로 변화하며, 너비 조절도 3D 형상에 반영합니다. ‘돌려 보기’로 시점을 바꾼 뒤 상·하·옆면에 문양을 찍거나 직접 그릴 수 있습니다. 문양은 표면 교차점과 법선, 그림은 표면 위 선 좌표로 저장합니다. 기존 SVG는 이전 작품과 형태 선택용으로 유지합니다.

그림 인식(`drawing.js`)은 서버나 외부 AI 없이 학·구름·연꽃 템플릿과 선 모양을 비교하는 제한적인 후보 제안입니다. 확신이 낮으면 모른다고 표시하며, 사용자가 그림의 뜻을 정할 수 있습니다. 그린 문양의 주문 점수는 사용자가 확인한 뜻을 사용합니다. 작품함과 사진 저장은 완성된 3D 화면을 보존합니다. 상감은 파기→채우기→표면 정리를 단계별로 표현하며, 투각은 실제 표면 삼각형을 제거해 앞뒤가 보이도록 뚫고 구멍 안쪽의 림을 표현합니다.

도감의 기존 다섯 예시에는 `assets/models/detail/`의 상세 원본을, 추가 18개에는 PR #1의 출처 기록이 있는 GLB를 사용합니다. 자료 출처와 해시는 해당 폴더의 `provenance.json`과 `assets/models/README.md`를 참고하세요.


### 예시에서 주문으로

`example-orders.js`는 도감의 23개 예시를 제작 분류·세부 모델·주문·문양 조건에 연결합니다. 추가 모델은 PR #1의 GLB와 출처 기록을 그대로 사용합니다. 오리 연적/오리 향로, 조롱박 주전자/조롱박 병처럼 닮은 모양과 다른 쓰임을 비교할 수 있습니다. 새 주문은 모란·국화·매화·대나무·버드나무·포도·풀꽃·글자를 포함하며, 복합 무늬 주문은 각 무늬를 모두 확인합니다. 그리기 인식 후보는 여전히 학·구름·연꽃으로 한정하고, 다른 문양은 학생이 뜻을 정할 수 있습니다.

주문서에 세부 형태·기법·필요 무늬를 표시하고 참고 예시를 바로 열 수 있습니다. 도감을 본 것만으로 제작 형태가 자동 선택되지는 않습니다. 새 주문의 특징 10점은 세부 모델·모든 무늬·기법·쓰임에 맞는 장식을 함께 확인합니다. 기존 주문 ID와 저장 형식은 유지하며, 옛 작품의 `modelId`가 없으면 기본 형태를 사용합니다. 무작위 주문은 전체 순환 내 중복을 막고, 가능한 경우 직전과 다른 쓰임을 우선합니다.

원본의 장식 기법과 학습자가 새로 꾸미는 기법은 다를 수 있습니다. 모란 주전자의 역상감·풀꽃 주전자의 퇴화·시문 병의 새김 등 원본 정보는 도감에 남기고, 게임의 새 문양은 지원하는 상감·투각·무문 표현으로 단순화합니다. 시기 미정 기린 향로를 고려시대 진품으로 단정하지 않습니다.

### 한 화면 아케이드 작업대

빌드 진입점은 `app-v3.js`입니다. `arcade.css`는 크롬북의 1366×768·1280×720·1024×600·1536×864 화면을 기준으로 작업대와 도구를 한 화면에 배치합니다. 기본 게임에 페이지 스크롤이 없으며 상세 주문, 학습 자료, 작품 소개는 별도 대화상자에서 엽니다. 휴대폰 전용 화면은 만들지 않습니다.

- `sculpt-game.js`: 선택한 실제 3D 형상의 화면상 윤곽을 구하고, 마우스·터치패드로 따라 깎습니다. 방문한 윤곽의 비율과 위치에 따라 형상이 드러나며 흙 조각이 떨어집니다. 방향키와 스페이스바 조작도 지원합니다. 이미 만든 옛 작품은 강제로 다시 깎게 하지 않습니다.
- `openwork.js`: `three-bvh-csg`의 HOLLOW_SUBTRACTION으로 스캔 표면의 실제 삼각형을 제거합니다. 닫힌 입체 무늬를 앞뒤로 관통시키며 안쪽 림을 추가합니다. 원본 메시를 따로 보존하여 되돌리기·기법 변경을 지원합니다. 2-manifold가 아닐 수 있는 박물관 스캔에 가상의 닫힌 고체를 강요하지 않습니다. 새로운 투각 무늬는 학습용으로 단순화했으며 실제 구조 강도를 계산하는 CAD는 아닙니다.
- `kiln-game.js` / `arcade-rules.js`: 건조 타이밍, 유약 칠하기, 초벌·재벌 온도 유지 미니게임입니다. 스페이스바를 누르면 온도가 오르고 떼면 내려갑니다. 초록 구간에 머문 시간을 모아 완료하며 과열·과냉각은 재도전합니다. 일시정지·화면 전환 시 누르기 상태가 풀립니다. 게임의 온도 게이지·시간은 학습용 단순화이며 실제 온도 수치나 제작 시간을 뜻하지 않습니다. 미니게임 실수나 속도는 학습 점수에 영향을 주지 않습니다.
- `characters.js` / `assets/characters/`: 이미지 생성으로 만든 다섯 손님의 앞·뒤·양옆 시트를 사용합니다. 사용자 제공 고려 복식과 공방 배경을 참고한 창작 일러스트입니다. 각 방향은 동일 시트의 해당 구간을 표시하며 손님 도감에서 모두 관찰하거나 원본 PNG를 저장할 수 있습니다.

주문은 카운터의 손님 대화로 받고, 흙 준비 → 성형 → 장식 → 가마 → 선별 → 카운터 전달로 화면을 전환합니다. `stations.css`와 새 `assets/scenes/`의 평면 일러스트가 작업별 큰 작업 공간과 상단 재료 트레이를 구성합니다. 캐릭터도 같은 차분한 파스텔·갈색 윤곽선 화풍으로 다시 제작했습니다.

- `clay.js`: 몸통용 태토와 상감용 백토·자토를 구분하고 여섯 번 반죽합니다. 선택한 색흙을 상감 표현에 반영합니다.
- `inspection.js`: 재벌 뒤 정상·금·뒤틀림·유약 불균일의 네 연습용 비교품을 분류하고 이유를 확인합니다. 학생이 만든 작품은 그대로 보존합니다.

도자기는 `MeshToonMaterial`의 4단계 명암·따뜻한 가장자리 잉크·미세한 종이 질감으로 표현합니다. 사실적인 반사 환경과 유약의 플라스틱 같은 광택은 사용하지 않습니다. 이는 Live2D SDK가 아니라 3D 형상을 활용한 2.5D 일러스트 렌더링이며, 자유 회전과 실제 투각을 유지합니다. 관찰 도감은 원본 자료의 표현을 유지합니다.
