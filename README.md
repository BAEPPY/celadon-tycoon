# 청자 공방

초등학교 5학년 사회 「고려청자의 우수성과 다양한 쓰임」 수업을 위한 개별 주문 제작 게임입니다.

## 수업 흐름

가상의 왕실·귀족 주문을 선택하고, 다섯 형태(베개·주전자·향로·의자·매병) 중 쓰임에 알맞은 형태를 판단합니다. 상감·투각·무늬 없는 표현을 선택하고, 장식과 건조→초벌→유약→재벌 과정을 진행합니다. 완성품의 쓰임과 솜씨를 설명하고, 고객 피드백을 보고 다시 만들 수 있습니다.

- 기본 활동: 13분, 주문 한 건 완성 후 서로 다른 쓰임 비교
- 자동 점검: 쓰임 40점, 제작 과정 30점, 주문 특징 10점
- 자기점검: 쓰임 설명 10점, 우수성 설명 10점. 문장 길이와 자기확인 여부만 검사하며 내용의 정확성을 자동 판정하지 않습니다. 교사가 최종 확인합니다.
- 속도나 그림 실력, 무작위 결과는 채점하지 않습니다.
- 주전자 몸통의 투각은 이 게임의 단층 모형에서 물이 새므로 주문 특징 점수를 얻지 못합니다. 역사 속 모든 투각 주전자를 일반화한 판정이 아닙니다.

## 저장과 개인정보

학생 이름·로그인·서버 데이터베이스를 사용하지 않습니다. 제작 중인 작품과 완성품 최대 30건은 각 브라우저의 localStorage에 저장합니다. 다른 기기와 자동 공유되지 않으며 브라우저 기록을 삭제하면 지워질 수 있습니다. PNG 작품 카드를 내려받아 교사가 안내한 패들렛 등으로 직접 공유합니다. 글꼴을 불러올 때 Google Fonts에 접속하며, 글꼴을 불러오지 못해도 기본 글꼴로 동작합니다.

## 실행과 검증

Node.js 20 이상에서 추가 패키지 없이 실행합니다.

```sh
npm start
# http://127.0.0.1:4173
npm test
npm run build
```

`dist/`를 정적 호스팅에 게시합니다. Vercel은 `vercel.json`의 buildCommand와 outputDirectory를 사용합니다. 서버 함수나 API 키가 필요하지 않습니다.

검증한 기능: 주문 5개, 상감/투각/무늬 없음 제작, 잘못된 순서 안내, 형태 오류와 재제작, 자기점검 분리, 개인 작품함과 진행 복원, PNG 저장, 모바일 가로 넘침 방지.
